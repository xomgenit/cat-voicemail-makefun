## The entry

> Beep. I knocked your call off the table. It was in my way.

## How it works

`main.ts` writes the greeting to `entry.txt` inside the output directory
(`MAKEFUN_OUTPUT_DIR`, defaulting to `out/`), checks it against the 1–120
character gate, and reads the file back to confirm it matches byte for byte.
